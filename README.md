📥 Download & Installation

1. Explore the application collection.
2. Choose an application that interests you.
3. Open its corresponding GitHub Releases page.
4. Download the latest available version.
5. Follow the installation instructions provided with that application.

**Windows users:** Download the `.exe` installer when available.

**Android users:** Download the `.apk` file when available. Install only applications from sources you trust.

**PWA users:** Open the application link in a supported browser and use the browser's installation option if available.
